# Архитектура

## Что это

FastAPI-обёртка над скрейпингом transfermarkt.com. Форк upstream, дополненный национальными
сборными и тренерами. Каждый вызов эндпоинта — живой запрос к TM (кэша нет).

## Слои

```
endpoints (FastAPI, app/api/endpoints/)
    │
    ▼
services  (dataclass-скрейперы, app/services/)
    │  TransfermarktBase: make_request → request_url_bsoup → request_url_page (lxml)
    ▼
schemas   (pydantic v2, app/schemas/)
```

- `utils/xpath.py` — все XPath-константы (включая `NationalTeams`).
- `utils/regex.py` — регулярки (DOB, цвета, id из URL).
- `utils/utils.py` — хелперы: `extract_from_url`, `safe_regex`, `safe_split`, `to_camel_case`.

## Конвенции

- **camelCase** в ответах: `alias_generator=to_camel` в `schemas/base.py`. Исключение — `/coaches/
  {id}/profile` (сырой dict в snake_case, без схемы).
- **Числа** парсят валидаторы `base.py`: «€1.2m» → 1200000, «1,85m» (рост) → 185; `parse_str_to_int`
  ожидает **строку** — int уже передавать нельзя.
- null/дефолтные поля вырезаются (`response_model_exclude_none=True` / `exclude_defaults=True`).

## Форк-модули

- `national_teams/` — most-valuable (проходит все страницы рейтинга), search, profile (наследует
  клубный), players (состав, + `shirtNumber`).
- `coaches/` — profile: name, image_url, citizenship, current_club{id,name}.
- Фикс upstream: `shirt_number` в `schemas/players/profile.py` сделан опциональным.

## Ловушки

- **`extract_from_url`**: должен срезать схему+домен (`https://www...` → `/...`) и ловить
  `AttributeError` от `re.match` → None; иначе канонические URL сборных/страниц валят парсинг 500.
- **Рост (`parse_height`)**: TM пишет его в разных локалях — `1,83m`, `1.83m`, `1'83m`, даже с
  юникод-примом `1′83m`. Парсер вытаскивает только цифры; если это упустить — клуб с такой
  страницей упадёт в 500 (`ResponseValidationError`).
- **Возраст в составе сборной** — второй `td.zentriert` (`[2]`), не первый (это игровой номер).
- `coach_id` из этого API **недоступен** — тренеры берутся парсингом `/mitarbeiter/` скрейпером.
- Скорость: поиски сборных делают N запросов подряд (по числу страниц) — помнить про лимиты TM.
