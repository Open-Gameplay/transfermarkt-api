# Эндпоинты

Проверено живыми запросами 2026-08-29. Все ответы — camelCase, ключи — TM-id.

## Игроки — `/players`

| Эндпоинт | Что даёт |
|---|---|
| `GET /players/search/{name}` | id, name, position (короткая), club{id,name}, age, nationalities[], marketValue; пагинация |
| `GET /players/{id}/profile` | полный профиль: fullName, imageUrl, placeOfBirth, height, citizenship[], isRetired, position{main,other}, foot, shirtNumber, club{id,name,joined,contractExpires}, marketValue, agent, outfitter, socialMedia |
| `GET /players/{id}/market_value` | marketValue + история `[{age,date,clubId,clubName,marketValue}]` + ranking |
| `GET /players/{id}/transfers` | трансферная история (clubFrom/To, date, season, marketValue, fee) |
| `GET /players/{id}/stats` | ⚠️ слабый, часто пустой |
| `GET /players/{id}/jersey_numbers` | история номеров по сезонам, включая сборные |
| `GET /players/{id}/injuries` | история травм: season, injury, fromDate, untilDate, days, gamesMissed |
| `GET /players/{id}/achievements` | трофеи/титулы: title, count, details{competition, season, club} |

## Клубы — `/clubs`

| Эндпоинт | Что даёт |
|---|---|
| `GET /clubs/search/{name}` | id, name, country, squad, marketValue |
| `GET /clubs/{id}/profile` | colors[] (HEX), stadium, foundedOn, league{id,name,tier}, squad{size,avgAge}, эмблема |
| `GET /clubs/{id}/players` | **состав**: position (детальная), dateOfBirth, age, nationality[], height, foot, joinedOn, signedFrom, contract, marketValue |

## Сборные — `/national-teams`

| Эндпоинт | Что даёт |
|---|---|
| `GET /national-teams/most-valuable` | ~250 сборных: id, name, country, confederation, marketValue |
| `GET /national-teams/search/{name}` | то же для одной |
| `GET /national-teams/{id}/profile` | как клубный профиль, colors[], league (UNLA…) |
| `GET /national-teams/{id}/players` | состав: id, name, **shirtNumber**, position (широкая: Goalkeeper/Defender/…), age, club, marketValue |

## Тренеры — `/coaches`

`GET /coaches/{id}/profile` — name, image_url, citizenship, current_club{id,name}. **snake_case,
без схемы.** `current_club` — всегда объект `{id, name}`, но `id`/`name` внутри могут быть `null`
(тренер без клуба).

## Соревнования — `/competitions`

| Эндпоинт | Что даёт |
|---|---|
| `GET /competitions/search/{name}` | id (ES1/ES2…), country, clubs, players, totalMarketValue, continent |
| `GET /competitions/{id}/clubs` | seasonId + clubs[{id, name}] |

## Ограничения

- Веса игрока **нет** нигде (только height).
- `coach_id` и короткого названия клуба (shortname) API не даёт — см. [[архитектура]].
- Схема сборной даёт широкую позицию; детальную даёт клубный состав того же игрока.
