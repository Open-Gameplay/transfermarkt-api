# Глоссарий

Словарь проекта. Термины читаются и дописываются здесь, а не в корневом `CONTEXT.md` (он — только
указатель на эту страницу).

Формат: `**Термин**:` + определение + `_Avoid_:` + список запрещённых синонимов. К термину
добавляется вики-ссылка на страницу подсистемы, если такая есть.

## Термины

**Эндпоинт**:
Один роут API (`app/api/endpoints/`). Список и что отдаёт — [[эндпоинты]].
_Avoid_: «роут» без уточнения (можно, но термин — эндпоинт)

**TM-id**:
Строковый идентификатор сущности на transfermarkt.com (игрок `8198`, клуб `131`, сборная `3377`,
лига `ES1`). Единый ключ в ответах API.
_Avoid_: «айди», «номер» без контекста TM

**Скрейпинг** (scraping):
Прямое извлечение данных из HTML transfermarkt по XPath. Каждый вызов эндпоинта — живой запрос к
TM, кэша нет.
_Avoid_: «парсинг» (можно, но скрейпинг точнее — мы тянем HTML, а не JSON)

**camelCase**:
Конвенция ключей ответов (alias_generator в `schemas/base.py`). Исключение — `/coaches/{id}/profile`
(snake_case).
_Avoid_: «snake_case» для полей API (это исключение, не правило)
